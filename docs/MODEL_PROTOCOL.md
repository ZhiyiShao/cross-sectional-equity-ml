# Ridge 与 LightGBM：训练及验证协议

本协议和 `config/baseline_models.json` 在本轮第一次拟合前写入。固定 21 个特征，训练期 2015–2019，验证期 2020–2021。本轮不合并训练与验证重训，不生成或评价 2022 年以后的预测。

## 数据与预处理

Parquet 读取时即按日期和阶段过滤，仅将训练、验证记录送入流程；再检查最晚信号日期和标签终点。读取原文件哈希用于完整性验证，不分析测试期观测。保留全部候选，为全部候选生成预测，监督学习损失及 IC 才采用已知主标签、信号日可选且不跨阶段边界的样本。缺失标签不参与拟合，不能以此筛选未来回测的事前候选。

只用训练期可用于损失的样本估计每个特征的 0.5% / 99.5% 分位点和中位数；先按训练分位点缩尾，再填训练中位数，再按训练均值与总体标准差标准化。常量列的尺度设为 1；全缺失列中止。Ridge 和 LightGBM 共用该 21 列矩阵，不加缺失指示列，不缩尾目标，不根据验证结果修改预处理。每条股票—信号日样本等权拟合。

## 固定参数预算

- Ridge：20 个对数等距 alpha，范围 0.01 至 1,000,000，带截距，Cholesky 求解。scikit-learn 的 alpha 作用于残差平方和目标，其尺度与样本数有关。
- LightGBM：叶子数 7/15/31/63/127 × 树数 100/300 × 最小叶节点样本数 100/500，共 20 组。固定学习率 0.03、L2=1、随机种子与四线程，不使用验证集早停，也不在结果出来后扩展网格。
- 20 日动量：原始 `momentum_20`，越大排名越前；缺失用训练中位数填补。不根据结果反转方向；不缩尾该排序基线。

两个模型只用训练标签拟合，按验证期逐信号日 Spearman Rank IC 的等权平均值各选一组；精确相同选网格中先出现者。常量预测的相关系数为缺失，不能填零。两模型和动量在完全相同的主标签样本上比较。

## 报告与边界

报告主标签覆盖分母、训练期样本内和验证期 Rank IC 均值、正值比例、逐年结果；Ridge 与 LightGBM 另报预测误差。正 IC 表示排序方向一致，不能直接转换成收益率。

对选定两模型的验证期逐日 IC 差做配对循环移动区块 bootstrap，主区块为 10 个信号日（约 50 个市场交易日），5 / 20 为预设敏感性，5,000 次。该区间条件于本次选出的模型，**没有校正同一验证集调参的选择偏差**，不能当作最终独立检验或保证未来有效。

冻结选定模型及预测后，用可用的退市冻结对价近似标签扩大验证评价样本，单独报告，不参与调参，也不把未知事件填零。非随机缺失和真实结算仍是限制。本轮不生成组合净值、Sharpe 或扣费收益；完整回测仍须处理实际持仓和退市结算。

配置、脚本、来源与模型产物记录哈希；模型、预测、逐日 IC 和图表均保存在 Git 忽略的 `outputs/baselines_v1/`，不上传授权行情。

接口依据：[Ridge](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html)、[LightGBM Regressor](https://lightgbm.readthedocs.io/en/stable/pythonapi/lightgbm.LGBMRegressor.html)、[训练与预处理的数据泄漏注意事项](https://scikit-learn.org/stable/common_pitfalls.html)。运行以本地锁定版本为准。
