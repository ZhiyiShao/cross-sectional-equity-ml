# 现金与换股对价记账规则：验证期事件核验版

本版只核验2020–2021实际持仓触及的事件，不训练、不预测、不打开测试集，也不覆盖原冻结应收款回测。已核实条款与到账假设分别保存。尚未取得供应商完整分配明细的事件保留争议标志，不能用“NA”质量标记替代条款核验。

## 三种日期与四类资产

分别记录权利生效日、每日估值日、可用/可交易日。登记日不是到账日；公告预期支付日不是已核实券商到账日。保留现金、固定金额现金应收、可交易股票、未到账股票权利四类资产。股票权利即使未到账也按继受证券当日价格/总收益计价，不能冻结成固定金额现金。

## 转换与防重复

在经核实的转换估值日，以事件前股票价值除以最后有效未复权价格得到等效股数。现金对价、特别分配及股票换股比例分别乘该股数。注销原股票，同时新增各项权利。一次性记入新资产合计减旧股票价值的损益，不再同时乘CIZ终值收益或DLRET。特别股息若此前已在持仓总收益中计入，事件登记必须扣除该腿，禁止再加；信息不足则中止该事件的正式记账。LVGO本地事件前记录Ret与Retx一致，事件后有争议的终值仅作对照，不作为新事件核验的输入收益。

股票换股采用稳定PERMNO映射；同Ticker可能重用，不据简称拼接历史。事件日用当日价格初始化换入资产，次一交易日开始计入继受证券总收益，避免重复计入事件日价格变化。日后分红再投资、分数份额沿用原研究的总收益单位近似；不是税后逐笔券商股份账本。未知价格或未知继受证券不得填零。

## 到账、处置与费用

有可信支付/交付证据时记录其日期与来源；券商实际可用日期缺失时，不宣称已核实。为验证实现，统一设事件后第2个市场日为现金/股票可用日，另列0/5/20日延迟敏感性；这些是固定情景，不按收益挑选。存在公告预计支付日时，可用日期不得早于该预计日，但仍标为假设。LVGO特别股息的公告预计日为2020-11-03。

继受股票权利在等待期持续承担价格风险。可用后，在下一个原策略调仓收盘（含可用当日恰逢调仓）卖出继受事件批次，失败则保留至下一调仓。直接收到现金不收交易费；法律换股本身不收买卖手续费；实际卖出按原定单边10bps收费。卖出所得先列结算应收，验证期按T+2市场日转可用现金；结算转移不产生第二次收益。不预支、不过桥借款。

现金仅在到账后可用于后续原策略调仓。本轮独立事件批次核验到账后留现金，不替其他股票再投资，因此其结果不能解释为重跑后的组合收益或年化收益。最终集成全组合时必须统一普通买卖结算规则，不能一边将普通卖出即刻再投资、一边声称整个账本已完全执行T+2。

## 未核实事件与验证边界

未知对价、CVR、跨市场换股及无法明确分配是否重复的事件，进入待核实状态；不得猜现金、默认全部损失或事后删去股票。验证交易只能使用截至2021-12-31的数据，出界支付或处置保留应收，不查看2022价格。测试前还需对全部实际触及事件完成登记，并在统一规则下重跑验证期；事件测试通过不等于整套策略已完成公司行动改造。

本轮交付包括LVGO终值桥接、已核实现金及换股事件登记、独立事件批次逐日账本、合成边界测试、供应商字段待补清单和报告。原模型和历次回测保持不变。
