# 参数稳健性实验执行入口与核验

本次实现对应[冻结方案](PARAMETER_ROBUSTNESS_V2.md)。冻结网格、80 次新增拟合预算、48 个复用候选窗口及两窗口评价规则保持原样。

**后续执行已完成：** 真实 48 个旧候选通过复用核验，80 次新增拟合全部完成，统一评价与独立产物核验通过。结果见[参数稳健性统一报告](../results/parameter_robustness_v2/README.md)。最终拟合、组合回测及 2022–2025 表现读取均为 0。以下保留入口机制及最初合成核验说明。

## 默认入口

```powershell
python scripts/train_models.py robustness-v2
```

默认仅校验冻结配置、12 个依据文件哈希及 128 个任务的预算结构；不读取本地特征、旧模型或预测，不创建正式实验目录，也不调用 fit。

正式执行入口为 `python scripts/train_models.py robustness-v2 --execute`。该分支先完成全部旧产物核验，再运行固定任务，输出候选预测、逐日 IC、候选汇总与拟合账本。现有实验已经完成，普通重复执行会拒绝覆盖。

`--execute --resume` 只恢复经过哈希核验的已完成任务并继续尚未开始的任务。已有实验目录不能被普通执行覆盖。失败、已预占但未完成的任务，以及未释放的写锁，都需要先审查；不会因重新运行命令自动重试或补预算。

## 日期隔离与旧候选复用

实现入口：[parameter_robustness.py](../src/equity_research/models/parameter_robustness.py)。

1. 只从明确列出的两个开发期产物目录读取数据，不遍历历史回放、测试预测或持仓目录。记录输入、代码和当前软件环境，供执行中及恢复时核验。
2. 先读取日期、资格、标签终点和特征列；目标值分别按训练／评价窗口读取，Parquet 过滤器在读取时限制信号日期及标签终点。跨截止日的标签不会送入训练或 IC 评价；完整当日候选仍用于特征排名及预测。
3. 校验原冻结配置、快照来源哈希、原拟合账本和候选覆盖。树模型复用要求已记录的 LightGBM 版本一致；Ridge 加载时将 sklearn 的版本不一致警告作为错误。原记录未提供全部依赖的版本史，其他依赖通过统计量与预测复算检查兼容性，并记录本轮版本用于恢复。
4. 对每个窗口、设计，独立复算训练行的截尾、中位数、均值及缩放，核对已保存状态、特征顺序、训练行数与最大标签终点。继续使用原状态转换，不保存或替换任何预处理状态。排序模型与对应回归模型的预处理文件须逐字节一致，并核对原记录中的哈希。
5. 核对 48 个旧模型的参数、特征顺序、全部评价候选行及预测；使用 SciPy 独立重算逐日 Spearman，核对原逐日 IC、均值和样本覆盖。任一候选缺失、不一致或出现未定义 IC，整轮停止，不能偷偷重新训练旧候选。

全部复用检查完成后，才允许进入新增拟合阶段。此路径先通过虚构旧产物测试，随后真实 48 个候选也已全部通过完整复用核验。

## 拟合账本

实现：[robustness_ledger.py](../src/equity_research/models/robustness_ledger.py)。

- 任务键由窗口、设计和候选 ID 组成；冻结调度为 48 个复用任务和 80 个新增任务。
- 每次拟合操作前，先将 `running` 预占记录刷入磁盘，再调用估计器。失败与中断占用预算；已预占任务不自动重试。准备阶段在操作内失败时也保留占用，采取保守记账。
- 账本通过同目录临时文件、flush/fsync 和原子替换持久化；独占写锁阻止并发执行。进程硬退出后可能留下锁，需确认进程状态后人工审查，程序不自动删除锁以重试。
- 完成任务绑定模型（新增任务）、预测、逐日 IC 和摘要的哈希；恢复时校验任务定义、输入与代码、环境和完成产物。漂移或损坏都会停止执行。
- 个股预测、模型、输入访问记录和账本只写入忽略的 `outputs/parameter_robustness_v2/`。正式执行不覆盖任何旧实验文件。
