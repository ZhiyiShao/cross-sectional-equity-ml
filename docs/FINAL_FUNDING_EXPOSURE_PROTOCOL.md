# 最终资金规则持仓暴露与贡献诊断

仅使用final_funding_backtest_v1的2020–2021、lag_2、10bps六组合实际持仓、交易、事件和净值。无拟合、无预测、无策略重跑。旧产物保留。

日前股票风险敞口包括普通股票与尚未到账的继受股票权利；后者以继受证券的PERMNO匹配特征和行业，不能当现金。交易应收应付和固定公司行动现金应收没有股票风险。分列日前已结算现金、交易应收、交易应付、公司行动应收及净资金余额；不以现金毛额解释闲置仓位。

沿用旧诊断的日前最近信号快照、14自然日上限、市值log/20日波动/60日beta及合格股票池20/60/20分桶。继受股票若没有已有特征快照则归未知，不重算或向未来补值。历史SIC有效期对齐；SIC年度版可有历史修订，不保证未经修订的历史发布版本。

证券损益=期末普通及继受股票−期初股票−买入+卖出+公司行动转换调整。事件日给原证券加全部新对价，同时从继受证券扣除新增股票初始价值，确保转换当日损益归原证券日前类别。以后继受股票的价格风险归继受证券。固定金额现金权利到账、交易应收应付结算没有新收益。再减该证券实际交易费用得净贡献。所有日级证券净贡献必须加总为NAV变化。

各年净贡献按本组合年初NAV归一化，可加总为年度收益；相对等权贡献之和等于年度收益差。月度贡献也保留年初归一化列以加总全年；另提供按月初归一化的月收益贡献，二者不混用。行业/风格贡献混合配置、行业内选股、时点与费用，不宣称为因果alpha，不跨维度累加。
