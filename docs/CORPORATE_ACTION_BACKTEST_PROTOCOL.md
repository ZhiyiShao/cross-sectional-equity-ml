# 公司行动完整验证期回测协议

固定2020–2021验证期、原100个信号及六组合、原预测文件、t+1收盘执行、五交易日调仓、Top10%与并列规则。无拟合、无新预测、不读取测试期，不覆盖旧产物。

登记39个原持仓退市事件，来源为WRDS退市查询11807755（39行）与分配查询11807760（100行，包括期间普通分红）；只以事件日对应分配腿替代终值，不重复普通总收益内分配。现金腿由供应商两表交叉核对，换股比例以发行人/SEC公告核对。CZR与EV按未选择默认对价；不进行最优对价选择。LVGO及ALXN股票腿估值与供应商差额保留，按法律股数乘事件日继受股票价格记账，未知供应商估值原因不作猜测。

以CRSP DlyDelFlg对应DelDlyDt作为日频账本转换日，最后原股票有效价估算持有股数。法律完成在上个交易日盘后的事件在下一市场日账本转换；供应商payment date不自动视为投资者可用日。现金对价、特别分配、继受股票权利分别记账。继受股票首次按转换日收盘初始化，次日起按总收益单位估值，即使未到账也保留风险。碎股、普通分红DRIP近似沿用旧研究口径。

主情景公司行动事件后2个市场日可用，特别分配不早于其记录支付日；0/5/20日固定敏感性。这是操作到账假设，不是券商凭证。继受股票与信号主动持仓分批管理，可用后的下一原调仓收盘卖出事件批次；未成功成交保留，下个调仓重试。若同一继受证券亦入选目标，继承批次卖出与主动买入分别计成本，不净额免手续费。

所有卖出款（普通与继受）先记扣费后的结算应收，T+2市场日可用。买入当日从已结算现金全额预留成本与本金，不借用未结算卖款、不融资。到账后仅在下个原调仓日按当日目标再投资，不追补旧单。目标金额仍按含应收总净值分配，买入需求统一按可用现金缩放后屏蔽不可成交证券，失败预算留现金。这是保守已结算现金账户约束；不是允许同日卖款购买的保证金账户模型。

比较路径固定：旧冻结应收/普通卖款立即可用 → 新公司行动/普通卖款立即可用（继受卖款仍T+2）→ 新公司行动/全部卖款T+2。中间层只作差异归因，不替代主情景。总计96个到账×成本×组合情景，加6个中间层情景。成本固定0/5/10/20bps，主情景10bps。没有根据结果选参数。

期末仍按2021-12-30清仓扣费；跨出评价窗口的卖款结算应收保留在NAV，不读2022行情、不声称期末全为可用现金。现金无利息。
