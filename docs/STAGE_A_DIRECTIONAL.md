# 阶段 A：五个方向性特征的配对实验

本轮检验在原有 33 个特征上增加五列，能否改善同一模型对未来五日超额收益的排序。配置在合成验收前冻结，SHA-256 为 `2c68fe465d5c59194a23378e58b0a53c6f3cacfc565b5eecaf71576474f4e633`。完整参数（含种子、损失函数和排序等级）见[冻结配置](../config/stage_a_v3.json)。

| 38 特征候选 | 33 特征对照 | 固定参数 |
|---|---|---|
| Ridge | 0a ridge_enhanced / R02 | alpha 1000，Cholesky 求解 |
| LightGBM 回归 | 0a lightgbm_enhanced / L03 | 63 叶、100 棵树、叶节点至少 500 行 |
| LightGBM 排序 | 0a ranker_enhanced / L00 | LambdaRank，7 叶、100 棵树、叶节点至少 500 行 |

四个窗口依次评价 2018、2019、2020、2021 年，训练从 2015 年开始，截止于评价前一年底。训练和评价都用原五日截面。原 33 列直接来自 0a 使用的开发期快照；新增列按日期、PERMNO 和信号资格对齐，依次为 positive_fraction 的 5/20/60 日与 gain_share 的 5/20 日。新增列沿用 12 个背景特征的原值截尾、填补与标准化，每个窗口仅由合格训练行估计统计量。训练标签资格与值逐行核对。评价从每个同族对照原预测重算逐日 IC，对齐合格标签键、值和可评价日期。

每个窗口预占三次拟合，合计 12 次，三个 33 特征对照全部复用。账本、模型、预处理、逐股预测、逐日配对 IC 和比较结果写入独立本地目录 `outputs/v3_stage_a_directional/`。对每个模型，四窗口平均差严格大于零且至少三个年份提高才采纳。95% 区间采用每窗口 10 个信号日的循环区块、2,000 次抽样，在窗口内共享抽样日期，再对四窗口等权。区间供解释使用。

### 入口

在 Project 的虚拟环境运行：

```powershell
.\.venv\Scripts\python.exe scripts/stage_a_v3.py
.\.venv\Scripts\python.exe -m pytest -q tests/test_stage_a_v3.py
```

第一条只读取冻结的公开配置、来源摘要和代码，不创建账本。第二条在临时目录使用虚构股票、日期、标签和对照预测。可选的 `--check-inputs` 在未来正式执行前校验真实开发期输入，`--execute` 才会启动正式拟合。失败、运行中断都占一次预算；只有任务之间暂停且已完成产物哈希有效时，`--execute --resume` 才能继续。正式运行前应从工作区重新核对冻结哈希和账本状态。
