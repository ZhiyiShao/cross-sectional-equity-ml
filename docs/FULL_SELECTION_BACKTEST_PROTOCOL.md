# 冻结验证预测组合回测协议

本轮不再训练或选参。使用2020至2021验证期既有预测，四组模型、正方向20日动量、同可选池等权基准全部评价。配置在计算组合表现之前冻结于 `config/full_selection_backtest.json`。原研究规则保持不变；下列估值与结算假设用于补足现有数据无法识别的执行细节，不代表核实了真实成交或支付。

## 日期与选股

仅读取信号日2020至2021的预测，以及2020至2021内配套日收益、成交状态和日历。100个完整信号从2020年1月6日至2021年12月21日，次一市场日收盘下单，最后持有期结束于2021年12月30日。2021年12月29日信号跨入测试期，不下单。2020年1月6日以现金净值1开始，不继承训练期持仓。

事前可选池仅使用冻结 `signal_eligible`，不读取主标签是否存在来选股。模型和动量各取ceil(N/10)只，同分按PERMNO升序；等权基准取全部可选证券。信号资格与入场时可买状态分开。每5个市场日再平衡，期末只清仓而不建立新仓。

## 持仓与成本

以每只证券的总收益单位价值记账，允许分数份额；CRSP含分红收益在原证券内再投资，不另外计分红再投资手续费。这是持仓价值模拟，不是完整逐笔股份及支付日回放。买卖发生在日收益入账后的收盘，故新买股票不享有当日入场前收益。现金零收益，不借款、不做空。

每只目标价值为交易前净值除以目标股票数。先卖出超额的可成交持仓；无法卖出的保留。根据卖出后现金及买入成本，对全部待买额度统一同比例缩放，再只执行可买部分，失败买入额度留现金、不补选、不转配给其他股票。固定单边成本0/5/10/20 bps，10为主结果，0用于毛收益对照。费用按实际模拟成交金额计，不能用成员更替率代替。滑点与佣金合并为这一简化费率，不另行假设容量。

报告平均再平衡单边资金换手 `(买入金额+卖出金额)/(2×交易前净值)`，包括首次建仓、不含期末清仓；期末清仓的成本仍计入净值。每次交易核对现金非负、持仓非负以及交易后净值等于交易前净值减费用。

## 退市与缺价

预审在潜在等权持有路径上发现39条已知NA/DD退市事件、一组MP/P1跨期记录及6条不可买记录；这些是预审路径计数，正式账本仍按实际持仓重新记录，不预先排除相关股票。

退市收益已有数值且满足旧异常政策的有效性条件时，只入账一次，并把持仓转换为不可交易应收资产。主情景冻结该估值至验证结束；另设退市后5、20个市场日释放现金的敏感性。三种情景都不是已核实结算，冻结也不是保证保守的收益下界。应收资产占用资金，其剩余市值计入终值并单独披露，不能称为已实现清算现金。

缺价MP日保留原收益缺失，仅以最后可知估值暂记资产，显式标记估值不确定。后续P1至P9到达时，验证起止价格、跨度及中间全为MP后，一次入账整段收益；不能把该收益提前分摊。若实际持仓出现未解决的其他异常、跨度未验证或期末仍有待解决跨期收益，中止正式指标生成。缺价期间的净值与日风险指标属于估值近似，报告不得把它们称为精确可观察收益。

## 评价与交付

报告总收益、CAGR、零无风险利率Sharpe、年化波动、最大回撤、资金换手、现金及应收占比，分2020与2021；主比较为同成本同结算情景下策略CAGR减等权池CAGR。CRSP市场作为额外未扣成本背景，从首笔入场收盘后开始累计。实际日持仓生成净值，不拼接5日超额标签。

72组固定研究模拟为6种策略×4种成本×3种结算假设；全部披露，不能用最优组合重新选模型。保留本地交易、持仓、异常账本以及可分享的聚合结果，证券级记录保持Git忽略。合成测试验证执行时点、成本、自融资、失败买卖、冻结对价、缺价衔接和测试期隔离；主情景独立重建现金持仓净值与指标。

## 本轮模型与版本

本轮仅替换预测来源为 `outputs/full_train_selection_v1/selected_predictions.parquet`。原始 Ridge alpha=0.06951927961775606；排名 Ridge alpha=1128.8378916846884；原始 LightGBM leaves=127、trees=100、min_child=100；排名 LightGBM leaves=31、trees=100、min_child=500。四组均在2015–2019训练并按2020–2021平均Rank IC选参。预测文件已冻结，零新增训练、零新增预测；继续封存2022–2025。

交易、成本、结算、日期和资金规则与旧协议一致。固定72组模拟，输出独立存于 `outputs/full_selection_backtest_v1/`，旧模型、预测、回测和暴露产物保留。新旧模型的动量及等权基准逐日结果应相同，作为回归核验。验证期已用于选参，报告结果不作为未参与开发的样本外证据。
