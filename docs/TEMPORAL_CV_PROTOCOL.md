# 训练期内部时间交叉验证协议 v1

本协议和 `config/temporal_cv.json` 在首次拟合前冻结。当前问题是：相同的原始收益目标和模型预算下，横截面排名特征是否改善训练期内部的时间泛化？不改变股票池、交易时点、21 个特征定义、未来五日标签或主标签事件政策。

## 范围与折

只读取信号日期在 2015–2019 且原阶段为 train 的记录。2015–2016 训练、2017 内部验证；2015–2017 训练、2018 内部验证；2015–2018 训练、2019 内部验证。同一日期的股票不拆开。原 2020–2021 验证集不进入本轮拟合、选参和复核，2022–2025 测试集继续封存。不拟合完整 2015–2019 的最终模型。

监督样本要求信号日可选、主标签状态为 ok/ok_bridged、标签有限，且标签终点在该折训练或验证区间结束前，并晚于信号日。每折按真实标签终点重新净化边界，不能只复用原 2019 边界标记。全部验证候选保留并预测；未来标签可得性只用于计算损失和指标。存储的不可评价候选标签置空，不输出其未来结果。

## 两种输入表示

1. **raw：** 沿用原始因子值，在每折训练监督样本上拟合 0.5% / 99.5% 缩尾、中位数填补、均值和总体标准差。
2. **cross_sectional_rank：** 对每个信号日、每个特征，以当日 signal_eligible 且该特征有限的全部股票为排名总体，不使用标签或标签可得性。并列取平均名次，变换为 `(rank - 0.5) / n - 0.5`。该特征当天只有一个有效值时为 0；全缺失则保持缺失。不合格候选及缺失特征保留 NaN，随后用该折训练监督样本的排名中位数填补。排名理论边界固定为 [-0.5, 0.5]，不再估计分位缩尾点；均值和总体标准差仍只在折内训练监督样本上拟合。

两种表示分别估计各自的训练期变换；Ridge 与 LightGBM 在同一表示下共享完全相同的输入矩阵。每折全缺失训练列中止，常量列标准差设为 1。原始主标签保持不变，不加缺失指标、不做目标缩尾或目标排名。此比较是两套输入处理流程的比较，不能单独归因于某一个数学变换。按日期分别排名可在构建折之前计算，因为未来日期不会影响过去日期。

## 固定预算与可比性

- Ridge：lambda = 1e-6 / 1e-4 / 1e-2 / 0.1 / 1。`alpha = n_train * lambda`，使平均平方误差加正则项的惩罚尺度在不同训练样本量下可比；带不受惩罚的截距、Cholesky 求解。
- LightGBM：叶子数 15 / 63 / 127 × 最小叶样本 100 / 500，共 6 组。固定 100 棵树、学习率 0.03、L2=1，其余参数见配置。不增加模型容量维度，不早停、不根据结果修改预算。
- 两种表示 ×（5 + 6）= **22 组配置**；每组三折，共 **66 次拟合**。每个模型/表示各选一组，不另做全期重训。四线程，固定种子。
- 20 日动量保持原始正方向，缺失填该折训练监督样本的原始中位数；不拟合方向、不参与 66 次模型预算。
- 同一候选配置在两个表示下成对比较，以避免只看各自最佳配置造成错误归因；所有模型使用完全一致的内部验证标签样本。

## 选择和输出

每个模型/表示按合并三折的全部内部验证日期平均 Rank IC 选参；日期等权，折的权重由有效日期数决定。精确同分按固定网格先后顺序。训练 IC 是样本内描述，不能参与选择。常量预测 IC 未定义时中止，不填零，也不静默删掉困难日期。

保存每折样本覆盖、预处理参数、全部 66 个模型、全部验证候选的各配置预测、逐日 IC、逐折训练/验证指标、22 组总分、同参数的表示差值、四组入选配置和图表。模型与证券级预测只存本地忽略目录 `outputs/temporal_cv_v1/`。使用 Unicode 安全的 LightGBM 文本序列化。

协议、配置、实现及过滤后的训练期输入摘要记入首次拟合前的 run_started.json。非空运行目录中止，防止无记录重复搜索。运行结束校验输入与旧产物哈希；独立重载模型核对预测、用 SciPy 重算 IC，并检查边界和排名总体。中途失败保留记录，不以改参重跑掩盖失败。

内部 OOF 指标参与本轮选参，不是嵌套交叉验证的最终无偏泛化估计。虽然本轮不使用 2020–2021，该区间及历次诊断曾影响研究方向，因此此次验证也不能抹去历史研究选择。每年有效信号日期约 50 个，均值变号或微小差异不自动显著。没有扣费回测，不宣称可盈利。
