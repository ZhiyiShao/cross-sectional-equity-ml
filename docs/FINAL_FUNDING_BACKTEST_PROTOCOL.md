# 最终资金账本验证期实施协议

本轮按 reports/FUNDING_AND_SETTLEMENT_POLICY.md 实施，先合成测试与历史日历核验，再运行2020–2021六组合。无重训、无新预测、测试集封存。

主情景：公司行动2个市场日可用，单边10bps；成功卖出普通或继受股票产生可复用交易应收；所有买入形成含费用应付。每个结算日的累计资金不得为负，证券敞口不超过净资产。公司行动应收在到账前不进入购买力。结算遵循独立公开历史日历，动作到账仍沿用固定操作假设。只在原调仓日交易，收盘同批次资金匹配沿用日频执行假设。

在查看本轮结果前固定预算：主机制下0/2/5/20市场日到账 × 0/5/10/20bps × 六组合=96情景；另运行2日到账/10bps的严格已结算现金敏感性六组合。共102情景，不据结果改规则。已结算现金敏感性也采用真实日期应收应付账本，不代表复现旧市场日加2近似。

新产物独立写入 outputs/final_funding_backtest_v1，不覆盖旧模型和回测。先复现旧全部卖款等待结算主情景六条净值路径，再核对新交易、持仓、应收应付与现金。最终报告对照最早冻结退市应收结果、上一轮受限资金结果及其普通卖款立即可用中间层。

公开日历仅登记2020–2021完整验证期及期末结算所需2022年1月初，另登记2017/2024制度切换合成测试窗口。未登记日期报错；测试期全日历扩展须在未来正式测试前完成，不据此加载测试行情。期末应收按面值保留，不查询期外价格。
