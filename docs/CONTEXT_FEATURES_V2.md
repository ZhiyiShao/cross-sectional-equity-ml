# 第二轮冻结设计：市场与行业背景

2026-11-07，训练前冻结。配置 `config/context_features_v2.json`，继承第一轮 `config/research_v2.json` 的时间、预算和交易规则。

训练/评价窗口：2015–2018 → 2019；2015–2019 → 2020–2021。两窗口内日期等权、窗口间等权，用平均 Rank IC 选择每种设计的配置；精确并列时取网格较早者。每窗训练标签结束日必须在训练截止日前，评价标签也不得跨评价截止日。严格标签仅用 ok/ok_bridged，不填充退市代理标签。

本轮四种设计：原始表示 Ridge × 原有/增强特征，排名表示 LightGBM 回归 × 原有/增强特征。21 个原特征保留，新增以下 12 个；增强后为 33 维。不将输入表示变化误解释为纯模型效果，同模型内部比较用于检验信息增量。

| 新特征 | 固定定义 |
|---|---|
| industry_mom20 / industry_mom60 | 同日合格股票、同 SIC 两位行业，20/60 日动量算术均值，包含本股票 |
| relative_mom20 / relative_mom60 | 个股对应动量减行业均值 |
| industry_rank20 | 行业内 20 日动量平均并列排名，(rank−0.5)/n−0.5 |
| universe_mean_mom20 | 同日合格股票 20 日动量均值 |
| universe_breadth20 | 有限 20 日动量严格大于零的比例 |
| universe_dispersion20 | 同日合格股票 20 日动量样本标准差，ddof=1 |
| universe_median_vol20 | 合格股票 volatility_20 中位数；该字段已经年化 |
| momentum_vol_interaction | 个股 momentum_20 × universe_median_vol20 |
| reversal_breadth_interaction | 个股 reversal_1 × (universe_breadth20−0.5) |
| momentum_dispersion_interaction | 个股 momentum_60 × universe_dispersion20 |

聚合只用当时合格股票和有限值，绝不根据未来标签是否可用筛选聚合样本。行业内对应动量有效数不足 5，或行业 Unknown，行业均值/排名回退到股票池对应统计。使用历史有效 SIC，仍受供应商历史分类修订限制。股票池状态是内部代理变量，不是额外宏观/外部市场指数。

Ridge 原特征与新增特征均使用本窗口训练样本的 0.5%/99.5% 截尾、中位数填补、总体标准差缩放。LightGBM 原 21 特征继续逐日横截面排名并训练期填补缩放；新增 12 特征走原值训练期截尾填补缩放，避免市场共同变量与交互信息在横截面排名后消失。两类模型的标签仍是原五日市场超额收益，不做目标排名或归一化。

| 模型 | 四组候选 | 固定项 |
|---|---|---|
| Ridge | alpha = 0.1、10、1,000、100,000 | cholesky，拟合截距 |
| LightGBM | num_leaves = 7、15、31、63 | 100 棵树、min_child_samples=500、learning_rate=0.03、L2=1、全样本/全特征、种子 20261107 |

无 early stopping。每种特征方案使用相同网格，4 设计 × 4 参数 × 2 窗口 = 32 次拟合。第三轮排序模型保留 16 次，本轮不动用六次最终拟合额度。选中候选直接复用各窗口已拟合的模型，不再额外训练。保存所有候选、预处理、评估预测、逐日 IC、拟合账本和冻结哈希。

评价先完成并保存选参，再回放四种入选设计的 2020–2021 年原前 10% 等权和第一轮风险约束组合，共八条路径。资金、公司行动和 10 bps 单边成本沿用第一轮。2019 只评价预测，因为本项目此前完整核验的公司行动组合账本从 2020 年开始；不将未经核验的 2019 事件补为零收益。组合结果不改变选参。

比较指标：逐窗口及等窗口平均 Rank IC、每年 IC、增强减原始逐日 IC 配对区块区间；组合净 CAGR、Sharpe、回撤、主动收益、换手及执行暴露。IC 区块长度 10 个信号日，2,000 次，种子 20261107。选中候选仍在选参窗口内评价，因此区间属于开发诊断，不是独立确认或多重选参校正。

2022–2025 年行情、标签、预测和表现不读取、不用于选参；已有文件仅枚举大小/修改时间，保护旧结果。新目录 `outputs/context_selection_v2`，公开组合汇总 `results/context_selection_v2`。运行 `python scripts/train_models.py context-v2`，非空实验不覆盖。
