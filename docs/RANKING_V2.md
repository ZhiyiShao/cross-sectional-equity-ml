# 第三轮：固定预算的 LightGBM 排序实验

2026-11-07 训练前冻结，配置 `config/ranking_v2.json`。继承第二版两个前推窗口、第一轮组合规则，复用第二轮已保存的 21/33 维特征及逐窗口预处理状态。

## 排序目标

每个信号日是一个 query。先排除不合格股票、不可核实标签及标签结束日越过训练截止日的样本，再按信号日、PERMNO 排序，保证 query 连续。标签使用原未来五日市场超额收益 y，按同日有效样本构造：

`relevance = min(9, floor(10 * (average_rank(y) - 0.5) / n))`

等级 0–9，收益越高等级越高。并列收益平均排名、保留同等级，不根据 PERMNO 伪造训练排序；所有收益相同的 query 不提供成对排序信号。分位只在本日合格标签中计算，不拟合全样本分位边界。推理仍覆盖全部当时合格股票，不用未来标签缺失过滤预测/选股池。

使用 LambdaRank，固定 `label_gain=[0,1,...,9]`、`lambdarank_truncation_level=53`、`lambdarank_norm=true`、`sigmoid=1`。53 接近约 500 股票池的前 10% 持仓规模，略高于 50，固定不调；样本数随时间变化时也不改此参数。线性增益避免最高收益档的指数放大；训练目标不是金额收益，也不直接优化实际扣费收益。

官方参数说明：[LightGBM Parameters](https://lightgbm.readthedocs.io/en/stable/Parameters.html#lambdarank_truncation_level)、[LGBMRanker](https://lightgbm.readthedocs.io/en/stable/pythonapi/lightgbm.LGBMRanker.html)。本地版本写入运行记录。

## 参数、预处理与预算

原有/增强特征分别比较 num_leaves = 7、15、31、63。其余继承第二轮：100 棵树、min_child_samples=500、学习率 0.03、L2=1、全样本/全特征、种子 20261107、确定性训练，无 early stopping。除排序专用参数和标签外保持一致。

原 21 特征逐日横截面排名；增强 12 特征保留原值训练期截尾、填补、缩放。直接复用第二轮同窗口 LightGBM 的预处理 JSON，不重新拟合，也不读取未来数据更新。原始/增强 × 四组树规模 × 两窗口 = 16 次拟合；第二、三轮累计 48 次候选额度全部用完，最终拟合额度本轮仍未使用。

两个窗口：2015–2018 训练 → 2019；2015–2019 训练 → 2020–2021。仍按连续收益标签的逐日 Rank IC 计算窗口均值，两窗口等权，再为原始/增强方案分别选择配置；精确并列取较小候选序号。保存选参结果后才能计算组合收益，不根据 NDCG 或组合表现改选。

## 对照及评价

复用第二轮保存的回归候选、预测和组合结果，无回归重训或重跑。报告各自入选配置对照，同时提供相同叶数下回归与排序的 IC 差，区分目标改变与树规模选择。

辅助诊断：连续标签 Rank IC、逐年 IC、NDCG@ceil(有效标签数/10)、最高十分位连续收益标签均值及有效覆盖数。NDCG 使用同一线性增益，预测分数并列按 PERMNO 排列。最高十分位先在全部合格股票中选，再剔除无法严格评价的标签；不把标签收益当作实际组合收益。

10 信号日循环区块、2,000 次、种子 20261107，报告逐窗口和两个窗口独立重采样后等权合并的排序减回归 IC 区间。区间是选参窗口上的开发诊断，不是独立确认或多重选择校正。本实验同时改变了损失与标签离散化，不能声称独立识别纯损失函数效应。
