# V3 研究结论

**五日超额收益的预测优势仍不确定。组合构建对交易频率和扣费收益的影响更清楚。** V3 最终采用 33 个价量、市场与行业背景特征，每五个交易日产生信号。训练目标是剔除行业、规模和 beta 后的五日残差收益，LightGBM LambdaRank 学习同日股票的相对次序。所有预测方案用原始五日超额收益的逐日 Rank IC 评价。

### 2015–2021 开发期

四个逐年前推窗口分别评价 2018、2019、2020 和 2021 年。先在每个窗口内等权平均信号日，再等权平均四年。候选替代配对基线需要平均提高且至少三年提高。配对置信区间按年对同一组信号日做循环区块重采样。

| 实验 | 结果与决策 |
|---|---|
| 训练频率 | 逐日训练相对五日训练，Ridge 平均 IC 增加 0.0033，两年改善。树回归下降 0.0016，一年改善。保留五日训练。 |
| 新增方向性特征 | 三组模型均未达到三年改善。排序树平均增加 0.0079，主要来自 2020 年。保留原有 33 列。 |
| 换训练目标 | Ridge 使用多期限联合目标后平均增加 0.0112，只有两年改善。树回归使用残差目标增加 0.0017，只有两年改善。排序树使用残差目标增加 0.0023，三年改善，成为该族的新基线。配对 95% 区间为 [−0.0155, 0.0195]。 |
| 模型与集成 | MLP 比同组 Ridge 提高 0.0067，三年改善，平均 IC 为 0.0028。多种子树回归、多种子排序树和三组等权排名集成的平均 IC 均低于各自对照。最终入选的残差排序树平均为 0.0115。 |
| 组合构建 | 固定预测后，在 2020–2021 比较六个组合方案，并回放股票池等权基准。入选方案沿用行业、beta 和个股上限，用训练期收益前三个主成分限制主动风险，加 0.15 倍权重变动绝对值惩罚。相对原 V2 约束，每次调仓平均换手从 44.27% 降至 12.86%，相对等权的扣费年化主动收益从 10.66% 升至 17.91%。两年均提高，收益差的配对区间为 [−4.88, 18.68] 个百分点。仅在原波动率约束下加入同样的换手惩罚，年化主动收益已达 17.67%。 |

阶段 0a 至 C 共新增 84 次正式拟合，分阶段为 12、8、12、32、20 次。另有 16 项复用。18 个预测改动对照经单侧循环区块检验及 Holm 校正后，最小校正 p 值为 0.149。阶段 D 在六条候选路径内计算的 deflated Sharpe 概率为 0.946，采用日收益、零无风险利率、名义路径数和观测 Sharpe 离散度。这一数字依赖日收益独立等假设，仅描述该组合搜索的条件结果。跨版本台账分别列示候选拟合、复用与重新拟合，同一配置可跨窗口出现。[拟合台账](trial_inventory.csv) · [预测多重比较](paired_ic_adjustment.csv) · [组合层校正](deflated_sharpe.json)

### 2022–2025 已见期回放

模型和组合先完成冻结，再用训练至 2021 年底的版本一次回放。以下为每个固定基准各自预定交易规则的结果。年化主动收益取策略与同路径股票池等权的逐日净收益差，再乘 252。CAGR 衡量净值复利增长。单边成本为 10 bps，沿用历史结算及公司行动账本。

| 策略 | 五日 Rank IC | 净 CAGR | 年化主动收益 | 最大回撤 |
|---|---:|---:|---:|---:|
| V3 残差排序树 | 0.0115 | 16.35% | 7.02% | −25.07% |
| V1 原始 Ridge | 0.0280 | 18.27% | 14.25% | −36.69% |
| V1 排名 LightGBM | 0.0137 | 11.56% | 9.48% | −43.25% |
| V2 增强 Ridge | 0.0251 | 13.44% | 5.41% | −24.75% |
| 20 日动量 | −0.0093 | 1.14% | −5.72% | −44.27% |
| 股票池等权 | 无排序信号 | 8.72% | 0.00% | −24.22% |

199 个五日截面包含 99,287 条合格标签。V3 减最佳固定 IC 基线（V1 原始 Ridge）的平均差为 −0.0165，配对 95% 区间为 [−0.0403, 0.0085]。V3 四年的净收益依次为 −16.72%、28.58%、27.35%、33.41%。将同一 V3 组合规则施加给所有信号后，V1 原始 Ridge、V1 排名树、V2 增强 Ridge 和动量的年化主动收益依次为 1.60%、4.75%、4.92%、−4.21%，V3 为 7.02%。整个截面的排序质量、投资组合实际持有的股票和交易成本回答不同问题。历史结果支持继续区分这三项，尚不足以确定 V3 具有可持续的新增预测优势。[历史回放明细](../v3_seen_replay/portfolios.csv) · [逐年 IC](../v3_seen_replay/rank_ic.csv) · [年度收益](../v3_seen_replay/annual.csv)
