# V3 阶段 0a · 四个逐年前推窗口的固定基线

同一组 V2 入选参数在四个年份给出了不同的模型排序。2018 年，四个树模型的 IC 均为正，两组 Ridge 均为负。2019 年增强 Ridge 领先，2021 年六组设计全部为负。

| 固定设计 | 2018 | 2019 | 2020 | 2021 | 四窗口平均 | 正 IC 窗口 |
|---|---:|---:|---:|---:|---:|---:|
| Ridge，21 特征 | −0.0062 | 0.0250 | −0.0037 | −0.0473 | −0.0080 | 1/4 |
| Ridge，33 特征 | −0.0082 | 0.0302 | −0.0160 | −0.0217 | −0.0039 | 1/4 |
| LightGBM 回归，21 特征 | 0.0160 | 0.0163 | 0.0013 | −0.0130 | 0.0051 | 3/4 |
| LightGBM 回归，33 特征 | 0.0152 | 0.0186 | 0.0274 | −0.0293 | 0.0080 | 3/4 |
| LightGBM 排序，21 特征 | 0.0015 | 0.0234 | 0.0213 | −0.0132 | 0.0083 | 3/4 |
| LightGBM 排序，33 特征 | 0.0157 | 0.0244 | 0.0092 | −0.0124 | 0.0092 | 3/4 |

每个窗口有 49 个可评价信号日。先按信号日计算预测分数与未来五日超额收益的横截面 Spearman 相关，再按日期和窗口依次等权平均。完整精度见 [逐窗口指标](window_metrics.csv) 和 [逐日 IC](daily_ic.csv)。

**2018 年削弱了增强 Ridge 领先的证据。** 首次单独评价这一年时，增强 Ridge 为 −0.0082，增强排序树为 0.0157。扩展到四个窗口后，增强排序树均值最高，与第二名原始排序树仅相差约 0.0010。这里衡量开发期排序能力；本阶段没有选出新主模型，也没有估算组合扣费收益。

**窗口口径。** 2019 年复用 V2 的同训练期预测，六个 IC 均与 V2 入选表吻合。2020 年复用 V2 第二个窗口的预测，再按当年标签终点截断。逐日文件实际少了两个信号日：2020-12-23 的标签结束于 2021-01-04，2020-12-31 的标签结束于 2021-01-11。交接文档预估少一天，此处按实际逐日核对记录。2021 年则在加入 2020 年训练样本后重新拟合。由于年份权重、训练截止和跨年标签均有变化，V2 两窗口均值与 V3 四窗口均值的差不能解释为策略改进幅度。
