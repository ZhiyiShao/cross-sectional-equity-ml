# V2 六组最终拟合

六组模型已按[冻结方案](../../config/final_evaluation_v2.json)各拟合一次，并完成独立核验。没有追加候选、改变参数、执行 2022–2025 回放或读取新的未见数据。本页记录训练交付，不包含新的绩效结论。

| 模型 | 特征数 | 固定主要参数 | 角色 |
|---|---:|---|---|
| ridge_original | 21 | alpha=1,000，cholesky | 主比较基线 |
| ridge_enhanced | 33 | alpha=1,000，cholesky | V2 主模型 |
| lightgbm_original | 21 | 回归，7 叶、100 棵树 | 回归基线 |
| lightgbm_enhanced | 33 | 回归，63 叶、100 棵树 | 排序目标对照 |
| ranker_original | 21 | LambdaRank，63 叶、100 棵树 | 特征消融对照 |
| ranker_enhanced | 33 | LambdaRank，7 叶、100 棵树 | 重点挑战模型 |

Ridge 使用原值特征；四组树模型的原有 21 维使用同日横截面排名。增强模型额外加入 12 个原值市场/行业背景特征。完整参数、角色和特征顺序保持冻结配置不变。

## 样本与预处理

- 候选：176,500 行；最终合格样本：**175,334 行、352 个信号日**。
- 信号日期：2015-01-02 至 2021-12-21；最大合格标签终点：**2021-12-30**。
- 原训练段 125,474 行，原验证段 49,860 行；恢复内部 2019–2020 边界的 497 条合格样本。
- 500 条标签延伸至 2022 年的候选被排除，其目标值未被请求读取。其他不合格行也不参与拟合。
- 三份训练期预处理状态重新估计：原值 21 维、排名 21 维、背景 12 维；组合为四种输入包，六模型共享对应状态。
- 特征聚合和排名先使用当日全部 signal-eligible 候选，再按严格标签过滤训练行。排序等级在最终合格行中按日期计算为 0–9。

[年度样本覆盖](annual_fit_coverage.csv)按**信号年份**统计，因此 2015–2020 的年末标签可以结束于下一年；全体样本的最终标签截止仍为 2021 年末。

## 核验与产物

[独立核验](verification.json)通过：NumPy 重算截尾、填补、均值和总体标准差，SciPy 重算横截面排名与排序等级，逐日逐行业核对背景特征，再加载模型进行预测。六组在全部合格训练行上的独立预测最大误差均为 **0**；核验过程没有调用模型拟合。

本地 `outputs/final_models_v2/` 保存模型、三份预处理、动量基准填补值、训练行、排序标签、序列化参考预测、六次拟合账本、访问日志及模型包。公开[哈希清单](manifest.json)绑定这些模型和状态；授权数据与模型权重继续留在本地。

原有研究产物的大小和修改时间均保持不变；冻结参数源哈希也通过检查。原有 V1 结果和主模型身份未改写。48 次候选预算和 6 次最终拟合预算均已使用完毕。

## 入口与后续边界

```powershell
# 已执行；若目录已存在会拒绝重跑，不会覆盖或继续花费拟合预算
python scripts/train_models.py final-fit-v2

# 独立复核已保存的模型；没有模型拟合
python scripts/verify.py final-models-v2

# 默认仅检查配置、模型包和哈希，不读取行情、标签或业绩
python scripts/evaluate.py v2-preflight
```

评价模块还提供 `predict_frame()`：只接受明确日期范围内、包含完整同日候选的特征与行业映射，拒绝标签列；固定预处理后生成六组预测及正向动量分数。已用首末训练信号日重放核验，与保存的训练参考预测一致，不计算样本内业绩。

`python scripts/evaluate.py v2 --release <release.json>` 是**审计后回放产物的评价入口**，不会自动获取行情或运行 V1 回测。它要求后续单独授权的 release、绑定相同模型哈希的回放审计、完整期间/日历/事件/账本核验和带哈希的两份 Parquet：六组风险约束组合日净收益、严格标签对应的六组预测。按冻结定义计算主要配对日收益差区间、逐日 Rank IC 和 NDCG；不足覆盖标记为描述性。

后续历史回放仍需准备 V2 的六组、两种组合和基准回放产物及完整辅助诊断，再交给该入口，不能直接把旧 V1 四组预测改名使用。新期还需访问资格、全年覆盖、日历与公司行动审核。本次未创建实际评价 release。

2022–2025 将标为“事后历史稳健性回放”；2026 的未见资格仍待审计。最终拟合完成不代表已获准读取这两段数据。
