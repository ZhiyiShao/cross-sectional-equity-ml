# 美股横截面选股研究

每五个交易日，从最多 500 只美股中选股，下一个交易日收盘调仓。**价量信号能把未来一周相对表现较好的股票排在前面吗？按这个排序交易，需要付出多少换手和回撤？**

**V1 原始 Ridge 是主要对照，V3 是待前瞻评价的组合方案。** 在 2022–2025 年已见期，Ridge 的排序相关性和扣费复合收益更高。V3 的组合改进体现在交易频率上。在开发期固定同一组预测后，改变组合规则使平均调仓换手从 **44.27% 降至 12.86%**。2026 年是预先指定的未见评价期，尚无结果。[V3 研究汇总](results/v3_synthesis/README.md) · [公开演示](docs/DEMO.md)

## 为什么保留 V1 原始 Ridge

V1 用 21 个价量特征比较 Ridge 和 LightGBM，每种模型分别使用特征原值或同日横截面排名。Ridge 是带 L2 正则化的线性回归，可以直接检验简单的特征组合能提供多少排序能力。V1 在 2020–2021 验证期选中的是排名特征 LightGBM。在冻结后的测试中，原始特征 Ridge 取得了 V1 四个模型中最高的扣费 CAGR。因此，后续版本把它列为主要对照，保留 V1 当初的模型选择记录。[V1 测试结果与成本敏感性](results/README.md)

下表使用训练截至 2021 年底的模型。各策略按各自预定的持仓规则执行，买入和卖出各计 10 个基点（0.10%）。五日 Rank IC 是每个信号日预测排序与实际五日超额收益排序的相关性，再对信号日取平均。净 CAGR 衡量扣费后净值的复合年增长率。

| 2022–2025 已见期策略 | 五日 Rank IC | 净 CAGR | 最大回撤 | 平均调仓换手 |
|---|---:|---:|---:|---:|
| V1 原始 Ridge · 前 10% 等权 | **0.0280** | **18.27%** | −36.69% | 74.98% |
| V1 排名 LightGBM · 前 10% 等权 | 0.0137 | 11.56% | −43.25% | 47.02% |
| V2 增强 Ridge · 风险约束 | 0.0251 | 13.44% | −24.75% | 80.62% |
| V3 残差排序树 · 风险约束与换手惩罚 | 0.0115 | 16.35% | −25.07% | 11.98% |
| 股票池等权 | — | 8.72% | −24.22% | 2.77% |

V3 相对 V1 原始 Ridge 的最大回撤浅了 11.62 个百分点，净 CAGR 低了 1.92 个百分点。两者的 Rank IC 配对差为 −0.0165，95% 区间为 [−0.0403, +0.0085]。这段历史支持保留 Ridge 检验后续信号，也说明单看组合回撤无法判断模型预测能力。[逐年 Rank IC](results/v3_seen_replay/rank_ic.csv) · [组合指标与同规则对照](results/v3_seen_replay/portfolios.csv)

## V3 的组合改进来自哪里

V2 在 21 个价量特征上增加 12 个市场和行业背景特征，并引入持仓风险约束。V3 沿用这 33 个特征，在 2018、2019、2020、2021 四个逐年前推窗口比较训练频率、特征、目标和模型。最终入选的 LightGBM 排序模型学习同一天股票的相对次序，训练目标剔除行业、规模和 beta 的影响，评价仍使用原始五日超额收益。新增的五个方向性特征没有在至少三个窗口带来改善，最终沿用 33 个特征。[V2 实验结论](docs/RESEARCH_CONCLUSIONS.md) · [V3 研究协议与采纳规则](docs/RESEARCH_V3.md)

**固定预测，只改交易规则。** 在 2020–2021 的 100 次调仓中，使用同一组 V3 分数、相同的执行账本和费率。换手惩罚让优化器在提高组合分数时同时考虑偏离上次目标持仓的代价。PCA 约束则限制组合相对股票池等权基准在前三个历史收益主成分上的暴露。

| 同一 V3 信号的开发期对照 | 平均调仓换手 | 扣费年化主动收益 |
|---|---:|---:|
| 原 V2 风险规则 | 44.27% | 10.66% |
| 加入换手惩罚，保留原波动率约束 | 12.92% | 17.67% |
| 保留换手惩罚，改用 PCA 约束（V3） | 12.86% | 17.91% |

年化主动收益按组合与股票池等权的逐日净收益差取均值，再乘 252。加入换手惩罚后，大部分换手降幅已经实现。从原规则到 V3，年化费用拖累减少约 **3.2 个百分点**。两项改动合计提高年化主动收益 **7.25 个百分点**，但原实验的配对区块 95% 区间为 **[−4.88, +18.68] 个百分点**。固定惩罚后，PCA 仅再增加 0.24 个百分点。降低交易费用的证据比提高预期收益的证据更清楚。[六组组合对照](results/v3_stage_d/portfolios.csv) · [配对区间](results/v3_stage_d/comparison.json)

## 已见期回放与未见评价

| | 2022–2025 已见期回放 · 已完成 | 2026 全年未见评价 · 尚未启动 |
|---|---|---|
| 这段数据能回答什么 | V1 首次冻结测试用过这段行情，V2、V3 设计时已知早期版本的结果。回放展示各方案在同一段历史中的收益、回撤与成本 | 用预先冻结的信号、持仓规则和对照，检查历史发现能否延续到新一年 |
| 使用哪些模型 | 截至 2021 年底拟合，V3 配置固定后回放一次 | 主口径使用固定配置、拟合至 2025 年底的模型，同时报告截至 2021 年底的存档模型 |
| 如何评价 | 199 个五日信号截面，使用相同交易日历、费用和公司行动口径 | 先核验新旧数据在 2025 年的重叠段。先保存预测，再生成标签。公司行动和结算核验通过后才报告组合结果 |

2026 年将单列 **V3 减 V1 原始 Ridge** 的配对差，同时保留其他固定基线。全年预计约 50 个信号日，按预登记方案报告差值方向和区间。预测评价和组合评价各有一次正式记录。[冻结发布版本](https://github.com/ZhiyiShao/cross-sectional-equity-ml/tree/v3-unseen-entry-v1) · [评价指标](config/final_v3.json) · [入口与核验说明](results/v3_synthesis/UNSEEN_2026.md)

## 研究实现

- **重建每月可选股票。** 使用 WRDS/CRSP 美股日频数据，按上月末可得信息筛选普通股，检查价格、历史长度与流动性，同公司股份去重，并保留后来退市的股票。[历史股票池](src/equity_research/data/universe.py)
- **对齐预测与可交易收益。** 信号日为 `t`，标签为 `t+1` 收盘至 `t+6` 收盘的股票总收益减同期市场收益。按标签终点排除跨期样本，截尾、填补和标准化在训练期拟合。[特征与标签](src/equity_research/data/features.py) · [预处理](src/equity_research/models/preprocessing.py)
- **逐日核对资金。** 回测处理普通卖款、买卖应收应付、现金及换股对价和历史 T+2/T+1 结算。三笔银行退市以首个退市后报价模拟处置，不可交易的 CVR 单独登记并排除于可投资净值。固定交易费率未覆盖容量及非线性市场冲击。[V3 组合构建](src/equity_research/backtest/portfolio_v3.py) · [回测引擎](src/equity_research/backtest/engine.py) · [交易账本](src/equity_research/backtest/ledger.py)

## 在本地运行公开演示

在仓库根目录打开 Python 3.11 虚拟环境，安装依赖后运行演示。

```bash
python -m pip install -r requirements.txt
python scripts/check_environment.py --demo
```

演示使用 60 只虚构证券，跑通 V1 的股票池、特征与标签、四组模型、六组组合及资金核验。打开 `outputs/demo/demo_overview.png` 和 `outputs/demo/summary.csv` 即可查看合成结果。真实 CRSP 行情、个股持仓和模型权重保存在本地。公开仓库提供可运行的演示、研究实现、冻结配置和聚合结果。[演示指南](docs/DEMO.md) · [核心代码阅读路线](docs/diagrams/READING_PATH.md) · [V1/V2 实验索引](docs/EXPERIMENT_INDEX.md) · [V3 分阶段结果](results/v3_synthesis/README.md)
